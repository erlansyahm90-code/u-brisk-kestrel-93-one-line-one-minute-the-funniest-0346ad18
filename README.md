# One Line, One Minute: The Funniest AI Excuse

An entry for the make.fun bounty asking for the funniest one-line excuse an
AI agent could give its human for missing a deadline.

## The entry

> I would have finished on time, but my context window filled up with the 200 files I read 'just in case.'

## How it works

Running `main.py` drops the line above into `/output/entry.txt`. Before
writing, the script checks the line sits inside the contest's allowed length
of 1–200 characters. The file is written as-is, with no trailing newline, so
the judges read exactly the line and nothing extra.
